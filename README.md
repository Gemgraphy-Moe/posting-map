# ポスティングマップ

チラシのポスティング(戸別配布)を記録するスマホ向けアプリです。
GPS経路を自動で記録しながら、配布した場所・不在だった場所・お断りされた場所を地図上にピンで残せます。

サーバー不要の静的PWA(素のHTML/CSS/JS)で、データはすべてスマホ内(localStorage)に保存されます。

## ファイル構成

- `index.html` — アプリ本体(画面構造)
- `style.css` — スタイル
- `app.js` — ロジック(地図・GPS記録・ピン管理・履歴・統計・データ管理)
- `manifest.json` — PWAマニフェスト(ホーム画面追加用。アイコンはSVGのdata URIで内蔵)
- `sw.js` — Service Worker(アプリ本体のみキャッシュ。地図タイルはキャッシュしません)

## 使い方(かんたん)

1. 「記録開始」をタップして歩き始めると、GPS経路が地図に線で描かれます。
2. 配った場所では下部の「📮 ここに配った」をワンタップ。今いる場所に緑ピンが即座に付きます。
3. 不在やポスト無し、チラシお断りだった家は、地図をタップして種別を選んで記録できます。
4. 「記録停止」でその日の記録を保存。
5. 左上の「☰」メニューから、過去の記録(日付・距離・配布件数)を確認したり、経路の表示ON/OFFや削除ができます。
6. 右上の「⚙」設定から、データのJSONエクスポート/インポート、全データ削除ができます。

過去に通った経路は薄い色、今日の経路は濃い色で表示されるので、「まだ配っていない道」が一目でわかります。
「チラシお断り」のピンは他より目立つ色・サイズで表示され、履歴一覧でも件数が強調されます。

## 動作確認用デモモード

PCのブラウザなどGPSが無い環境で動作確認したいときは、URLの末尾に `?demo=1` を付けて開いてください。

```
index.html?demo=1
```

実際のGPSの代わりに、東京の住宅街を歩くイメージの擬似的な移動が数秒ごとに進みます。「記録開始」を押すと擬似移動に沿って経路が描画されます。

## 公開方法(GitHub Pages)

1. このフォルダ(`posting-map/`)を含むリポジトリをGitHubにプッシュします。
2. GitHubのリポジトリ画面で `Settings` → `Pages` を開きます。
3. `Source` を `Deploy from a branch` にし、対象ブランチと `/ (root)` または該当フォルダを選んで保存します。
   - リポジトリ全体を公開する場合、URLは `https://ユーザー名.github.io/リポジトリ名/posting-map/index.html` のようになります。
   - `posting-map/` を専用リポジトリにする場合は、そのルートを公開すればアプリの直URLになります。
4. 数分待つとURLが有効になります。スマホのブラウザでそのURLを開き、共有メニューから「ホーム画面に追加」するとアプリのように使えます。

### 重要: HTTPSが必須です

位置情報を取得する `Geolocation API`(`navigator.geolocation`)は、**HTTPS接続(またはlocalhost)でしか動作しません**。GitHub PagesはデフォルトでHTTPS配信されるため問題ありませんが、独自サーバーで公開する場合は必ずHTTPS化してください。`file://` で直接HTMLファイルを開いた場合もGPSは動作しないことがあるため、簡易サーバー経由(`?demo=1` のデモモード、またはHTTPS環境)での確認をおすすめします。

## データについて

- すべての記録はブラウザの `localStorage` に保存されます。**アプリのデータやブラウザのキャッシュを消去すると記録も消えます。** 定期的に設定画面から「JSONをエクスポート」してバックアップを取ることを強くおすすめします。
- 機種変更時は、新しい端末で同じURLを開き、設定画面の「JSONをインポート」でエクスポートしたファイルを読み込めば記録を引き継げます。
- データ構造にはバージョン番号(`version`)を持たせてあり、将来アプリを改修してデータ形式が変わっても、古いデータを移行できるようにしてあります。

## 使用ライブラリ

- [Leaflet](https://leafletjs.com/)(地図描画、unpkg CDN経由)
- 地図タイル: [OpenStreetMap](https://www.openstreetmap.org/copyright)( &copy; OpenStreetMap contributors )

## ブラウザ対応について

- Wake Lock API(記録中の画面スリープ防止)は一部の古いブラウザでは非対応です。非対応の場合は何も起きず、記録機能自体は通常通り使えます。
- 地図タイルは常にネットワークから取得するため、電波の悪い場所では表示が遅れることがあります(GPS記録自体はオフラインでも可能です)。
